# ─────────────────────────────────────────────────────────────
#  Полные пресеты из экосистемы nfqws2-keenetic
#
#  Источники:
#    • github.com/nfqws/nfqws2-keenetic 1.3.1 — etc/nfqws2/nfqws2.conf
#      (стратегия по умолчанию пакета: NFQWS_ARGS + _QUIC + _UDP);
#    • чат t.me/nfqws («nfqws2 for keenetic/openwrt/entware»), выгрузка
#      сентябрь–октябрь 2026. Взяты только стратегии nfqws2 (--lua-desync),
#      у которых в чате есть подтверждение «работает» от автора или от
#      других участников; синтаксис nfqws1 (--dpi-desync=…) отброшен.
#
#  Перенос в наш формат:
#    • пути /opt/etc/nfqws2/… не нужны: блобы зовутся по именам, а
#      blob_registry сам дозаявляет --blob= (имена nfqws2-keenetic
#      tls_clienthello / quic_initial — синонимы наших google-блобов,
#      файлы побайтово совпадают);
#    • NFQWS_EXTRA_ARGS (режим list/auto/all) у нас — «Фильтрация» в GUI,
#      поэтому в пресетах хостлистов режима нет;
#    • опечатка «repeat=» (вместо repeats=) из оригиналов исправлена: lua
#      незнакомый ключ молча игнорирует, и повторов не было;
#    • голый «padencap» в аргументах multisplit убран: это значение
#      tls_mod=, а не ключ multisplit — lua его не читал.
#
#  ⚠️ Порты: firewall отправляет в nfqws2 только порты из «Настройки →
#  nfqws2 → TCP/UDP-порты». Если пресет ловит порт, которого там нет
#  (853 у DoT, 4192 у Wardogs), его надо дописать — иначе профиль не
#  увидит ни одного пакета.
# ─────────────────────────────────────────────────────────────
